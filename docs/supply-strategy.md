# Initial Supply Strategy (Single City)

No special infrastructure is built for this in the MVP.

1. Launch in one city only (e.g. Guwahati). Seed areas, colleges,
   and workplaces by hand so "near campus/office" search works on day one.
2. Manually source the first 100–200 listings: walk-in PGs/hostels near
   target colleges, plus a small set of owner-posted rooms/flats.
3. Admin verifies every launch listing (photos, address pin, rent/deposit
   plausibility, phone verification) before tenant marketing begins.
4. Only after verified supply + visit workflow work end-to-end do we invite
   tenants broadly. Demand without trusted supply churns.
5. Room/bed-level inventory, broker tooling, and payments come later, driven
   by actual partner requests — not speculation.
